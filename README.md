# Falling Sand Simulation (WIP)

A simple falling sand simulation built with TypeScript, PixiJS, and Vite.

## Try it here

[Demo](https://alexanderterezov.github.io/falling_sand_simulation/)

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (usually `http://localhost:8080` or with port 5173).

## Controls

- Left click: paint with the selected material
- Right click: cycle material (sand, stone, water, acid, eraser)
- Mouse wheel: change brush size

## Build

```bash
npm run build
```

## Features

- Simulated Cells (Sand, Stone, Water, Acid)
- Color Randomization
- Bloom effects
- Very simple UI
- Brush sizing
